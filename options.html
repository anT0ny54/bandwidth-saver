Image proxy

wsrv.nl
Images are rewritten to https://wsrv.nl/ before download. The original URL is sent with the selected quality and max-width options, plus `we=1` and `dpr=2` when width limiting is enabled, then returned as WebP with 1-day browser caching. Grayscale is added only when enabled.
